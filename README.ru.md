# Razer Macro

Ремаппер **макрокнопок M1–M5** на клавиатурах Razer без Synapse.
Один exe на ~5 МБ, без драйверов и фоновых служб, ~10 МБ памяти.

[English version](README.md)

Собрано и проверено на **BlackWidow Ultimate 2013** (`1532:011A`). Другие модели
с тем же протоколом должны работать — см. [Другие модели](#другие-модели).

## Зачем

M-кнопки не шлют скан-кодов, Windows их просто не видит. Они оживают только
когда клавиатура переведена в **driver mode** — это и делает Synapse, заодно
требуя аккаунт, лаунчер и пару сотен мегабайт резидентных служб.

Здесь та же работа в одном файле: перевести клавиатуру в driver mode, слушать
репорты макрокнопок, впрыскивать нажатия через `SendInput`.

## Установка

1. Скачать `razer-macro-windows-x64.zip` из [Releases](../../releases) и
   распаковать куда угодно — например в `%LOCALAPPDATA%\Programs\razer-macro`.
2. Запустить `razer-macro.exe`. Он сядет в трей и при первом старте создаст
   рядом с собой `config.toml`.
3. Автозапуск: галочка **«Запускать при входе в систему»** в меню трея либо
   `razer-macro.exe --install` (отключить — `--uninstall`).

В обоих случаях пишется одно значение в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` — без прав администратора,
без планировщика и без ярлыков в автозагрузке. Галочка в трее читает реестр при
каждом открытии меню, так что показывает фактическое состояние.

**Synapse нужно закрыть или удалить** — две программы не поделят устройство.

SmartScreen поругается на неподписанный бинарник: сертификат стоит денег, у
проекта его нет. Не устраивает — собери сам, это одна команда.

## Настройка

Правится `config.toml`, затем в меню трея — «Перечитать конфиг».

```toml
[keyboard]
vendor_id = "0x1532"
product_id = "0x011A"

[binds]
M1 = "^+{PRINTSCREEN}"   # Ctrl+Shift+PrtScrn
M3 = "{PRINTSCREEN}"     # PrtScrn
M5 = "#+s"               # Win+Shift+S
# M4 = "run:notepad.exe" # запустить программу вместо клавиш
```

Модификаторы в начале строки: `^` Ctrl, `!` Alt, `+` Shift, `#` Win.
Именованные клавиши — в фигурных скобках: `{PRINTSCREEN}`, `{F13}`,
`{VOLUME_UP}`, `{DELETE}`, стрелки, медиа. Остальные символы набираются как есть.

### Нумерация зеркальная

Маркировка M1–M5 идёт **снизу вверх**, а коды клавиатура шлёт **сверху вниз**.
Полезно знать до того, как удивишься не той сработавшей кнопке:

| Кнопка | M5 (верх) | M4 | M3 (середина) | M2 | M1 (низ) |
|--------|-----------|----|---------------|----|----------|
| Код    | `0x20`    | `0x21` | `0x22`    | `0x23` | `0x24` |

Вместо имени можно писать сырой код: `0x21 = "{VOLUME_UP}"`.

## Как это работает

1. Перечисляем HID-интерфейсы клавиатуры через SetupAPI.
2. Шлём feature-репорт **set device mode** (`class 0x00`, `id 0x04`, режим `0x03`)
   и читаем обратно командой `0x84`. Интерфейс, ответивший `0x03`, и есть
   control — он находится проверкой, а не захардкожен.
3. Читаем input-репорты с вендорской коллекции (`Col04`). Репорт макрокнопки —
   `04 <код> …`, причём в нём перечислены **все** удерживаемые кнопки, поэтому
   нажатие определяется разницей наборов, а не одним байтом.
4. Впрыскиваем привязанную комбинацию через `SendInput`.
5. На выходе: вернуть **normal mode**, отпустить залипшие модификаторы, закрыть
   хендлы.

Цикл чтения блокируется на overlapped I/O и событии остановки, поэтому в простое
демон не тратит процессор вообще — никакого поллинга.

### Другие модели

`razer-macro.exe --list` покажет все HID-интерфейсы Razer с их VID/PID — свой
вписать в `config.toml`. Если у модели другой transaction id вместо `0xFF`,
переключение режима не сработает: заведи issue с выводом `--list`.

## Память

Замерено на Windows 11, сборка с Python 3.14:

| Сборка | Процессов | Working set | Приватных |
|--------|-----------|-------------|-----------|
| папкой (`razer-macro-windows-x64.zip`) | 1 | ~27 МБ | ~15 МБ |
| одним файлом (`razer-macro.exe`) | 2 | ~35 МБ | ~16 МБ |

**Экономный вариант — папкой.** Однофайловый PyInstaller распаковывает себя во
временный каталог и держит процесс-загрузчик рядом с интерпретатором: удобно, но
это те самые лишние ~9 МБ. Одиночный exe оставлен для тех, кому важнее один файл.

Почему 27 МБ, а не 60:

- **Нет pystray и Pillow.** Иконка трея рисуется прямо в DIB-секцию и отдаётся
  в `Shell_NotifyIcon`, так что весь GUI — это ctypes.
- **Нет hidapi.** HID работает напрямую через `setupapi`/`hid.dll`, заодно из
  комплекта пропадает нативная DLL.
- Ненужные HID-интерфейсы закрываются сразу после того, как найдены control и
  коллекция макрокнопок.
- `SetProcessWorkingSetSize` после старта и раз в пять минут: демон почти всегда
  спит, и страницы, набранные при инициализации, возвращаются системе.

Дальше упирается в сам CPython. Заметно меньше — только перестав быть программой
на Python.

## Сборка

```
pip install pyinstaller
python -m PyInstaller --clean --noconfirm razer-macro.spec
```

Результат — `dist\razer-macro.exe`. Тег `v*` собирает бинарник на CI и цепляет
zip к GitHub-релизу.

Из исходников не нужно ничего, кроме Python 3.11+ (ради `tomllib`):

```
python razer-macro.py --console
```

## Если не работает

Лог: `%LOCALAPPDATA%\razer-macro\daemon.log`.

- **Ничего не происходит.** Synapse запущен? Клавиатура видна в `--list`?
- **Комбинация с модификаторами игнорируется**, а голая клавиша работает —
  приёмник сверяет флаг `KEYEVENTF_EXTENDEDKEY`. Список расширенных клавиш —
  `EXTENDED_VKS` в `keys.py`, добавь туда свою.
- **Клавиатура онемела после жёсткого убийства процесса.** Driver mode не был
  возвращён — переподключи USB.
